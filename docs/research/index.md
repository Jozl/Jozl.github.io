# 调研

长期调研项目按阶段发布：**每个节点发一次，原地修订，结论可能变化**。每篇都是阶段稿，不是终稿。

材料、过程笔记、来源台账都在私有仓里，成品由同步脚本发布——所以站上只看到提炼过的结论。

## 阶段怎么读

| 阶段 | 含义 |
| --- | --- |
| `r1` | 立项：问题定义 + 计划 |
| `r2` | 证据：核心证据链打通 |
| `r3` | 对抗：反例与边界条件 |
| `final` | 定稿：结论 + 局限 + 遗留 |
